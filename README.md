# Enamel Pin Creator

Standalone soft enamel pin tool for **Pinheads Pins**.

Upload or AI-generate pin artwork, then get:

1. **Stroke outline PNG** — transparent background
2. **Color vector SVG** — flat colors, PMS snap, mergeable palette

AI generation uses a Pinheads style profile learned from the shop catalog (pin art only, including sold-out pins — no cap product photos). **Attitude** is the through-line; **patriotism** is a major theme pillar.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
